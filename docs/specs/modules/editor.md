# Module Spec: Editor

## 职责与边界

编辑器壳（`project/src/editor/`）：面板化 UI、选择/命令/undo-redo、场景编辑工作流、Gizmo、资产浏览。管编辑交互与编辑器状态；不管引擎运行时逻辑（Application/Scene/Render 属 engine），也不直接持有渲染资源——场景画面经 `ScenePresentationSubsystem` 离屏输出 + `UIContext` surface 显示。代码风格见 `docs/editor/EditorCodeStyleGuide.md`。

## 公共接口

- 面板契约：`EditorPanel(id, title)`，虚函数 `OnAttach/OnDetach/OnUpdate/OnGui(const EditorFrameContext&)`；窗口经 `BeginPanelWindow/EndPanelWindow` 走 `UIContext`。全部面板：`AssetBrowserPanel`、`AssetPreviewPanel`、`ConsolePanel`、`InspectorPanel`、`SceneHierarchyPanel`、`TerrainModePanel`、`ViewportPanel`。
- 命令与 undo/redo：`EditorCommand`（`GetLabel/Execute/Undo/TryMerge/GetSelectionAfterExecute/GetSelectionAfterUndo/GetAffectedTerrainAssetId`，配合 `EditorCommandSelection`）、`CompositeCommand`；执行入队走 `CommandService`，历史栈在 `UndoRedoService`。常规命令由 `ExecuteCommand` 先执行再入栈；Engine 已原子完成的编辑（如 Terrain stroke 或 layer-stack mutation）只能走 `RecordExecutedCommand`，该路径不得再次调用 `Execute`，也不得进入开放 transaction（必须在命令仍由调用栈独占时同步回滚）。其三态结果明确区分 `Recorded`、`RolledBack`、`RollbackFailed`；历史存储失败时必须用同一命令的 `Undo` 回滚，调用方只有验证到 rollback generation 后才可继续发布，无法证明回滚时必须隔离该 authoring session，避免出现未被历史追踪的修改。`GetAffectedTerrainAssetId()` 默认 `noexcept` 返回零；`RemoveCommandsForTerrainAsset()` 同样是 `noexcept` 的 bool 合同，只删除目标 Terrain 的 undo/redo 项并重新映射 saved/current state，其他命令保持原有时间线顺序。事件监听器异常不得逃逸，也不得阻止 dirty 通知尝试；返回 false 时 reload 必须保持原状态并允许重试。
- 事件：`EditorEventBus`（类型索引的同步事件总线，`Subscribe<T>/Unsubscribe/Publish<T>`，非线程安全），事件类型在 `Core/EditorEventTypes.h`/`EditorEvents.h`。
- 上下文：`EditorContext`（SelectionService/SceneService/TerrainEditorService/UIContext 指针）供命令执行；`EditorFrameContext` 携带 `AshEngine::UIContext*` 供每帧 GUI。
- Services（全部，位于 `Services/`）：`AssetDatabaseService`、`AssetPreviewService`、`CommandService`、`DragDropTransferService`、`EditorGizmoService`（含 `EditorGizmoMath/Transform/Viewport/Style/SelectionUtils`、`MoveScaleGizmoTool`、`RotateGizmoTool`）、`EditorIconService`（接口 `IEditorIconService`）、`EditorSessionStateService`、`EditorSettingsService`、`EditorShortcutService`、`EditorViewportCameraService`、`EditorViewportService`、`SceneService`、`SelectionService`、`SelectionOverlayRenderer`、`TerrainBrushOverlayRenderer`、`TerrainEditorService`、`UndoRedoService`。`TerrainEditorService` 是 Terrain authoring session 的唯一 mutable owner；它异步加载 AssetDatabase snapshot，在 Editor `Update()` 中轮询，并把验证后的 `TerrainWorkingSet` 以值语义交给 UI-free `TerrainEditorSessionCore` 持有。`TerrainStrokeCommand` 只保存 asset/layer/sequence 与 Engine `TerrainEditPatch`；`TerrainLayerCommand` 只保存 asset/sequence、Engine `TerrainLayerStackPatch` 与变更前后选中层。两者 Undo/Redo 均回到 Function API 做身份、source state 和原子性校验；Editor 不实现第二套 patch codec 或回放器。
- Asset Browser 只能在当前 catalog epoch 内借用 `AssetDatabaseService::Find*` 返回的 `AssetInfo*`。Create/Rename/Move/Delete/Reimport 等可能同步 refresh catalog 的调用会使此前借用的所有指针失效；跨越该调用所需的 AssetId、相对路径或展示文本必须在 mutation 前按值捕获，完成后再从新 catalog 查询。`AssetDatabaseService` 每次实际进入 Engine refresh 都推进 Editor-local catalog revision（失败也可能清空 catalog）；`AssetBrowserFrameData` 捕获该 revision，list/icon item 在任何可调用 host action、drop mutation 或 item context action 的边界后先比较 revision，失配就配平 UI 栈并停止本帧借用列表。Panel 在 toolbar、directory、content、shortcut 与 content-menu 子阶段返回后按需从新 catalog 重建 frame data。Reimport 另使用 refresh 前复制的稳定相对路径执行操作、重新选择及写日志，不得在 refresh 后解引用旧 `AssetInfo*`。
- `EditorViewportCameraService` 为 Scene viewport 保存最近有效 scene/focus bounds，并按 bounds 在当前 view-space 的深度范围动态计算 near/far；projection 使用 reverse-Z。初始 bounds 未完整加载时保守保留/合并已有范围，资源完成后只在用户尚未导航时重新取景；orbit 上限随内容 framing distance 增长。初始取景、`F` 聚焦、滚轮/dolly/orbit/pan 与 Terrain 的有限正非均匀 scale 都走同一 bounds/clip 合同，不使用固定 2000 m far 或固定帧轮询。
- `TerrainEditorService` 的文件操作状态为 `AwaitingPublication -> Running -> PublishedAwaitingCatalog/Succeeded/Failed/Cancelled`；`Cancelled` 是 Import/Export 的独立终态，不复用 `Failed`。Save 先等待目标 generation 完整合成/发布，再把按操作所需的 immutable snapshot、自 persisted generation 以来的累积 Component payload、解析路径和 observed `TerrainContainerRevision` 交给 worker；worker 不捕获 service 或 mutable working set。Save/Optimize 调用 checked container API，由共享 destination commit lease 串行化并在 lease 内比较 expected revision；`SourceChanged` 保留 dirty/history 并允许重试，成功结果必须携带 `TerrainContainerSaveReport::committed_revision`。write time 只作为 committed revision 的辅助 metadata 在 worker resolve 前采样，UI 线程不得在稍后的 completion poll 才重新采样；写盘成功但时间采样失败仍按 operation failure 处理。成功只标记启动时捕获的 generation，更新编辑仍 dirty；失败保留 working data 和历史。Save 与 Optimize 只使用当前 working-set `source_path` 并拒绝显式目标路径；只有 Save Copy As 接受显式新路径，并通过同目录 staged 完整写入、回读校验和 `publish_staged_terrain_container_new` 创建副本。最终 publish 与 Save/Optimize 共用 destination lease，在 lease 内重新确认目标不存在并 durable、non-replacing 地发布；竞态目标、`Busy` 与失败均不得覆盖既有目标或留下临时件。Save Copy As 不重绑当前资产、不清 dirty。Optimize 仅允许 clean saved asset。所有生产或修改 `.AshTerrain` 的文件操作都要求有效 AssetDatabase root，canonical 生产路径必须留在 root 内且扩展名为 `.AshTerrain`，目录联接/符号链接不能逃逸；worker 不可用时快速失败，不回退到 UI 线程写盘。Running worker 允许后续编辑，但在完成前无条件禁止换资产、关闭或直接打开另一 snapshot，即使当前 session 已因 history rollback 失败进入 quarantine；`Shutdown()` 对可取消的 Running job 先请求取消，再等待所有 Running worker 完成，之后才释放 service 状态。
- Terrain Create/Import/Export 与保存共用同一 service-owned 文件作业槽，但不捕获 mutable Editor 状态。Create 与 Import intent 从同一对规范化 Target Size X/Z 草稿构建布局：每轴 256–8192 m、最近 2 的幂、中点向上、固定 256 quad/Component 与 1 m/sample，默认 2048 × 2048 m；Import 的 source width/height 独立于 target。Create intent 另携带由 UI height minimum/maximum 映射出的 `height_offset` / `height_range` 和 flat height；Import intent 携带完整 `TerrainHeightImportDesc`；Export intent 携带完整 `TerrainHeightExportDesc`，worker 另持有捕获 generation 的 `shared_ptr<const TerrainAssetSnapshot>`。派发 lambda 只能按值捕获 operation serial/kind、路径、descriptor/cancellation token、flat 参数或 immutable snapshot，禁止捕获 `[this]`、working-set 指针、panel state、intent 引用或 `_publishedSnapshot` 引用。`CancelFileOperation` 只接受 Running Import/Export，Create、Save 系列和非 Running 状态必须拒绝；Shutdown 同样驱动可取消 job 的 token 并等待 worker。取消与 worker final publish 共用原子 phase 作为线性化点：取消赢家走 `Cancellable -> Cancelled` 并保持到 future 消费/reset，worker 发布赢家走 `Cancellable -> Publishing -> Completed`，非取消提前失败可走 `Cancellable -> Completed`；worker 先 claim `Publishing` 后取消必须返回 false。取消保持当前 session/cache/dirty/history，清理 staged/`.import.tmp`，且 final destination 不得发布。
- Create/Import 的最终 `.AshTerrain` target 使用 root-relative UI 路径，经 canonical AssetDatabase root containment、扩展名和 non-existence 预检；最终仍必须通过唯一 staged container、完整验证和 `publish_staged_terrain_container_new` 的 named-lease non-replacing publish，目标竞态不得覆盖。Import 把唯一 stage 而非 final path 交给 `import_terrain_height_to_container`。Import source 与高度图 Export destination 属外部路径，不套用 `.AshTerrain` containment resolver：绝对路径可位于 asset root 外，相对路径以 asset root 为基准解析。Export 固定 create-new / never-overwrite，不提供覆盖开关；按所选 PNG/RAW R16/RAW R32F/EXR 格式验证 parent 和扩展名，以唯一 stage 做 non-replacing publish，并保留既有或竞态 destination。Create/Import 完成后只在 `Update()` 主线程 refresh catalog、解析真实 path-derived AssetId 并发布/打开；durable 文件后的 catalog/open 失败保留文件并进入 `PublishedAwaitingCatalog`，Manage 显示最终路径、重试状态与最近一次 catalog/open 错误。`TerrainImportReport` 的 PNG 8-bit 精度 warning 保留在 operation status。
- `TerrainEditorService` 的磁盘同步状态为 `None / Reloading / Conflict / RecoveredReadOnly / Failed`。source metadata 以 500 ms wall-clock 轮询；`TerrainContainerRevision` 是外部变化权威，write time 只作辅助记录。Windows named commit lease 只协调遵守 TerrainContainer API 的 writer；poll 遇到 `Busy` 时不读取过渡 header、不消耗连续失败 debounce 预算，candidate decode 遇到 `Busy` / `SourceChanged` 时恢复原状态并按可重试路径处理。同一 asset 的重复选择不会取消 pending future 或清诊断。candidate load 不写 AssetDatabase cache；clean reload 只在 `Update()` 边界提交 working set/published snapshot/cache 和选择性历史删除，历史门槛失败时回滚 cache 并保持候选与原状态。dirty 或物理 revision 回退只进入 Conflict，且共享 cache 仍发布本地 snapshot：Reload 应用已验证候选；Save Copy As 成功保存本地副本后应用候选；Keep Local 在磁盘有效 generation 之上推进本地代并对全 Component 重新 composition。恢复旧 descriptor 时，排序使用 rejected generation、内容使用最后有效 generation。Recovered/Failed 都是只读状态，仅允许 Repair 或 Save Copy As，且保留精确诊断。
- Terrain stroke 在 Begin 时冻结二维 world metric、brush/layer 参数和 lower-stack source，并建立只属于该 press/release 的 active transaction。Add 按到达顺序保存 raw sample；`Update()` 在没有 composition in-flight 且达到 80 ms wall-clock cadence 时，只对 resampler continuation 之后的新增路径 apply brush，再 compose/publish 该 generation 的完整 dirty 集合；End 强制冲刷尾段。Flatten target 在首个合法 resampled dab 处从冻结 source 采样一次并由 active stroke 跨全部 preview batch 持有；layerless stroke 的零压力首批只缓存最早 dab，不创建层或推进 generation，后续首个有效 batch 把该 dab 前置给 Engine，因此 one-shot 与增量分批等价；全零 stroke 在 End 直接丢弃缓存。每次增量 patch 会合并为 stroke 首次 before 到最新 after，中间 preview 不进入历史；完整拖动只用 `RecordExecutedCommand` 记录一个已执行命令。Cancel、失焦、apply/compose/publication 或历史记录失败会逆序回放聚合 patch并重新发布回滚结果；无法证明回滚时 preview 标为 `Failed` 且 session quarantine。layerless session 只有在第一个真正改变 canonical value 的 dab 才最终保留稳定 ID 的 `Edit Layer / 编辑层`，layer patch 与 stroke patch 合为同一命令；hover、空 stroke、全零压力/no-op 或 cancel 不留层、不变 dirty，Undo/Redo 同时删除/恢复同一层与内容。每次 stroke/undo/redo 仍以更高 operation serial 覆盖旧请求。Base Import 在 session 内不可变，working set 和每个 published preview generation 必须共享 source snapshot 的同一 Base R16 allocation；禁止为 8193² Terrain 按 preview 复制 Base 或整个 working set。
- Terrain layer action 支持 Add/Delete/Duplicate/Rename/Move/Visible/Opacity/Lock。Service 先调用 `apply_terrain_layer_stack_edit` 原子修改 working set，再用返回 patch 构造一个已执行命令；成功幂等操作返回空 patch，不推进 generation、不排 composition、也不进入历史。非历史 `SelectLayer` 只接受 working set 中存在的稳定 16-byte ID；BeginStroke 要求 intent layer、brush layer 与当前选中层三者一致。Layer command 显式保存变更前后选择，undo/redo 不从 vector index 猜测；锁定状态进入 preview 并阻止 BeginStroke，活动 stroke 期间拒绝切层和 layer action。记录失败沿同一 patch 回滚，并复用 stroke 的 generation、选择态、pending publication 验证与 quarantine 契约。
- `TerrainModePanel` 以稳定 `terrain_mode` / `Terrain` 身份注册、默认关闭并与 Inspector 共用右侧 dock。它只通过 `UIContext` 绘制 Manage/Sculpt/Paint/Layers。Hierarchy 只有在 primary selection 恰为一个有效 Entity、该实体含合法 `TerrainComponent.asset_path` 且 AssetDatabase canonical resolve 为 Terrain 时，才复用既有 `SelectAsset` intent；多选、非 Terrain、空/非法路径均不替换当前 session。面板第一次打开还会从 `SelectionService` 同步当前选择，解决先选实体后开面板没有新 event 的情况；旧的 Asset Browser 单一 Terrain 选择入口继续可用。所有 replacement 仍服从 dirty/conflict/pending composition/file operation/quarantine gate，面板不直接 load container 或丢弃状态。`TerrainAuthoringConfig` 由 `TerrainEditorService` 持有，面板只提交不可变 `ConfigureAuthoring` intent；半径、强度、falloff、spacing、64-bit seed、固定八个材质槽和当前稳定 edit-layer ID 均由服务再次校验。`BeginStroke` 只接受与服务真源逐字段一致的 Sculpt/Paint 配置，活动 stroke 期间锁住 mode tab 和配置更新。普通 Sculpt 页面允许同一地形编辑层使用 Raise/Lower/Smooth/Flatten/Noise，Paint 页面选择固定材质槽；UI 不再暴露 Additive/Alpha 实现分类。Layers 的选择和操作以 16-byte ID 定位，vector index 只作为单次 Move 的目标位置；rename/opacity 草稿以 asset + layer ID 为身份，并在无关 generation 变化时保留尚未提交的本地输入。Manage 页面提交 Create Flat、PNG/RAW R16/RAW R32F/EXR Import、四类来源 × 四种格式的 Export、Save、Save Copy As、Optimize、Reload 与 Repair，并显示文件/外部状态、精确错误和 Import warning。Create 默认 root-relative `terrain/NewTerrain.AshTerrain`、Target Size 2048 × 2048 m、height min/max `0/1024` 与 flat height `0`；Create/Import 共用 Target Size X/Z 草稿，严格十进制有效值在 Enter、失焦或 submit 时规范化，非法文本保持可见并阻止动作，旁边显示实际 Samples、Components 与 1 m/sample。Import 仍显式提供独立 source/target、源宽高、height mapping、RAW endian、X/Z flip、精确 EXR channel 和 Reject/Crop/Catmull-Rom；Export 使用另一组独立 destination/format/RAW endian/EXR channel/half-or-float/source/layer/material-index 草稿，输出字段明确说明 create-new / never-overwrite。材质权重 PNG/RAW R16 使用 `[0,1]` normalized 映射，RAW R32F/EXR 直接输出归一化浮点值。Cancel 控件只在 cancellable Import/Export Running 时绘制。Conflict modal 以 external-state serial 锁存稳定 popup ID，显示 local/disk generation，提供 Reload、Keep Local 与 Save Copy As；异步 Save Copy As 未完成或失败时 modal 保持打开。Recovered/Failed 状态显示 Repair/Save As，禁用覆盖 Save、Optimize、Create/Import、笔刷与图层 mutation；Export 仍须满足 immutable snapshot 和单文件作业槽约束。
- Terrain 的可排序非破坏 stack 在 UI/文档中称为 `Edit Layers / 地形编辑层`；固定八路 surface lane 称为 `Material Slots / 材质槽`。编辑层列表固定使用 `UIContext` table facade 的 Layer、Visible、Locked 三列并绘制表头：Layer 为 stretch，Visible/Locked 为 fixed；每行继续以稳定 16-byte layer ID 建立 ID scope，selectable 只占第一单元格，两个隐藏-ID checkbox 分居后两格，三者命中区域互不重叠。
- Terrain viewport 输入固定按 `Camera → Terrain → Gizmo → Selection` 仲裁。只有 canonical、primary、可接收输入的 Scene viewport，并且 Terrain Mode 面板打开、当前恰好单选一个解析到当前 session asset 的 Terrain Entity 或 Terrain asset 时，Sculpt/Paint 才拥有未修饰 LMB、brush overlay 与 W/E/R。authoring session 的 working set、dirty/history、tab/config/drafts 与该临时 tool ownership 分离；关闭面板、空选、多选、非 Terrain 或 identity mismatch 只让工具 fail-closed，不卸载或替换 session。活动 stroke 在该资格丢失时整笔 Cancel、清 preview，并继续消费已接管 press 直到物理 release；无活动 stroke 时立即归还 LMB、Gizmo、Selection 与 W/E/R。Alt/RMB/MMB、滚轮和 F 聚焦始终先交给相机，活动 stroke 遇到这些手势会取消。Terrain 接管 press 后锁存到物理 release，非 Ready 首击不会在按住期间状态转 Ready 后中途 Begin；Ready 首击同帧 Begin + 首采样，极短的 press+release 同帧还会立即 End，Ready release 先补末采样再 End。活动 stroke 命中 Outside 时结束已完成的有效段，Pending/Failed 时取消，随后同一 press 只继续屏蔽 gizmo/selection，避免重入后跨空白重采样连线；丢失 release edge 时，在 stroke 已不活动且物理 LMB 抬起后回收 latch。命中 entity 的 Terrain asset path 必须解析到当前 service 选中资产；sample index 乘 working-set spacing 转回 terrain-local 米，世界矩量保留 entity X/Z 非均匀缩放。Escape、Scene panel 折叠/关闭/Detach、content/presentation/primary/input 资格丢失会取消活动 stroke；严格的操作系统级全应用失焦仍属于后续多 viewport focus 聚合边界。旧 pending GPU pick 和框选状态在 Terrain 接管时清除；Manage/Layers 保持原 gizmo 行为。
- `TerrainEditorPreviewState.query_status` 只表示 authoring session 的加载/可编辑/quarantine 状态；实时光标命中保存在独立 `viewport` 子状态，包含 cursor query status、经归一化的 world center/normal、service-owned brush radius、选中 Terrain 的 scene entity ID 和显式 `has_world_position`。只有当前选中 asset、Sculpt/Paint mode 和 canonical primary Scene 可更新该状态；Outside、模式/主视口/输入资格丢失及 Scene panel 生命周期结束会清空。Pending/Failed 可保留同一 session 上一个合法 anchor 用于状态着色，但 foreign Terrain hit 不得发布新 anchor。该分离禁止 mouse Outside/Pending 反向禁用 Layers 或覆盖 session quarantine 语义，并为 world-space overlay 提供可查询地表的稳定 entity 身份。
- `TerrainBrushOverlayRenderer` 只消费 service preview、当前 immutable published snapshot、preview entity 的现行 axis-aligned world transform 与 Scene binding。它生成固定 64 段 world-XZ 圆并逐点查询 snapshot 高度；只连接相邻 Ready 端点，缺失 Component 留出 gap，不跨空白。session 非 Ready、Outside/无 anchor、非法 transform/binding、实体资产换绑或空线集均零提交；Ready 绿、cursor Pending 琥珀、cursor Failed/locked 红。Canvas 必须在 helper overlay 的当帧 clear 之后、2D box selection 之前，仅为 canonical primary 且可输入的 Scene 调用；提交只走 Function `SceneOverlayLine`/`submit_scene_overlay`，不访问 Graphics。
- Scene `Ctrl+S` 是由 `EditorActionCoordinator::Update()` 驱动的异步 continuation；`EditorApplicationImpl` 每帧必须先更新 `TerrainEditorService`，再更新 action coordinator。当选中的 dirty Terrain 确实被 active Scene 引用时，coordinator 先启动或附着到该资产的 Save，只在同一 operation serial 进入 `Succeeded` 后写 Scene。catalog miss 由 service 对资产根、working-set source path 与全部未解析 Scene 引用做顺序无关的 `Current / Different / Unsafe` 集合分类：任一 root-contained 的精确 `Current` 都能证明身份并优先于同集合中的 `Unsafe`；仅在没有 `Current` 且存在无法安全归一化的引用时 fail closed。Terrain failure 发布 Scene save failure并传递资产路径/原始错误；Scene content epoch 变化取消延后写入。Scene 写入后只在当前 undo/redo history state 仍等于 `Ctrl+S` 捕获的 checkpoint 时 `MarkSaved()`，否则保留新命令的 dirty 状态。
- Inspector：Camera/Light/Mesh/Environment/Particle/Terrain 六类 component editor 经 `InspectorComponentEditorRegistry` 注册，Name/Transform 由固定 section 绘制。Particle 草稿按 Main、Emission、Shape & Motion、Size Over Lifetime、Color Over Lifetime、Renderer 固定顺序分组，Main/Emission/Renderer 默认展开，尺寸与颜色各有只读的起止预览；Renderer 的 sprite Texture 字段支持搜索、Asset Browser 拖放和 recent paths，空路径显示 Default White fallback，已知缺失路径警告但可提交，已知非 Texture 类型阻塞提交，Soft Particles 关闭时 fade distance 控件禁用但保值。Particle 字段继续通过既有 draft/sanitize/`SetParticleComponentCommand` 提交，reset/restore/remove、保存重载、undo/redo 与连续字段 merge 语义不变。Terrain 的 `Add Component` 入口只在 entity 尚无 Terrain 且没有待提交 Terrain 草稿时可见；选择后先打开资产选择器，只有选中有效 `.AshTerrain` 才以 typed asset-backed `entity.add_terrain_component(value)` 提交，不能复用 intentionally fail-closed 的无资产参数通用 add facade。已有 Terrain 的后续修改走 `entity.set_terrain_component(value)`。Terrain 草稿编辑资产、可见性、投射/接收阴影及固定八层材质覆盖，提交为 `SetTerrainComponentCommand`；空/错误类型资产、无效材质覆盖或 Terrain 层级中非零旋转/非正缩放会阻止提交。Terrain 的 entity snapshot 使用专用序列化保留八层覆盖，复制、删除恢复和 undo/redo 不丢字段。
- readiness smoke：`Editor::_get_automation_readiness` 要求 bootstrap、UI renderer、AssetDatabase refresh 与 viewport presentation 同步成功；最终 ready 仍由 Application 的当前帧全 scene packet + asset epoch + present 公共契约证明。Editor 不生成 golden。

## 约束与不变式

- **Editor 只经 `UIContext` 与 Engine UI 交互，禁止直接使用 ImGui / Graphics API**：面板、控件、服务一律通过 `EditorFrameContext::pUiContext`（`ImGui/` 下的遗留桥接文件已被剔出构建）。
- 单一真源：活动场景状态唯一真源在 `SceneService`；Selection 只由 `SelectionService` 维护、undo/redo 栈只由 `UndoRedoService` 维护、viewport presentation 绑定只由 `EditorViewportService` 维护、Terrain mutable authoring session 只由 `TerrainEditorService` 维护；快捷键文案与触发规则同一真源（`EditorShortcutService`）。
- Gizmo 视觉与命中投影必须同源：Scene viewport 的中央 gizmo 与右上角 XYZ 指示器使用当前相机的同一 view basis；Move/Scale 平面手柄的世界四角必须逐点做透视投影，绘制和命中共用所得凸四边形。相机上下文不可用或投影退化时隐藏对应视觉，禁止回退到 identity 朝向或屏幕轴对齐矩形。
- Scene Viewport 相机移动：滚轮沿视线方向等步长平移 camera position 与 orbit target，不得随 orbit distance 缩短而减速；Shift 仅将滚轮、MMB Pan、Alt+RMB Dolly 的当次移动速度乘以 2，不得写回 Camera Speed 设置。Orbit 旋转灵敏度与 F Focus 不受 Shift 影响。
- 场景修改必须封装为 `EditorCommand` 经 CommandService 执行，保证 undo/redo 与选择一致性；面板间通信走 `EditorEventBus` 或 Services，不得互相直接引用。
- Particle 必须进入 entity snapshot 的复制/删除/撤销恢复路径。连续属性编辑只在 command 前后状态结构连续时合并；跨 saved checkpoint 不合并，最终状态等于初始状态时不得生成空历史项。
- Particle sprite 的空路径与已知缺失路径沿用运行时 Default White fallback，因此不得阻止 Inspector 提交；资产库能确认路径是非 Texture 类型时必须阻止提交。Soft Particles 开关只控制 fade distance 的可编辑状态，不得清空该值。
- 场景 new/load/reload 的重置语义由 `SceneWorkflowCoordinator` 统一执行：先做 Terrain preflight；Scene mutation 成功后按 Terrain session commit → 清 Selection → 清 UndoRedo → 选中默认实体执行。Scene load/reload 失败时原子保留当前内存 Scene、active path、Selection、history 与 Terrain recovery/error 状态，不激活 fallback Scene；未完成的异步 `Ctrl+S` continuation 也不会被新请求静默取消。primary viewport 唯一，viewport 共享状态只由 primary 发布。
- 稳定标识：action/panel/viewport 的 id、drag payload type 与 Terrain layer 的 16-byte ID 是持久化/交互契约；layer command 和选择不得持久化 vector index。
- 冻结快捷键（改动需用户确认）：Ctrl+N / Ctrl+R / Ctrl+S / Ctrl+Shift+R / Ctrl+Shift+A / Ctrl+Alt+A / F2 / Ctrl+Shift+P / Delete / Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z / F5，AssetBrowser 内容区 Enter/Backspace。
- 重构三原则：按面板/服务纵向深拆、不做横切层；`*Support` 文件只放无状态自由函数；主文件只做协调不塞业务。
- 改动定位：新功能先找最贴近的 panel/service/app/shell 文件落点，不默认塞 `EditorApplicationImpl.cpp`；panel 管 UI 与用户意图、service 管领域状态、app 管装配与生命周期、shell 管菜单/dock/状态栏，只在本层改。
- Editor 任务需要改 engine 侧代码时，仅限稳定接口/通用能力，且每处包裹 `// editor begin 修改原因：...` / `// editor end` 标记。
- 生命周期时序：`Editor` 构造函数只保存轻量配置，禁止 `HLog*` 与任何依赖 Engine 运行时的对象；`EditorApplication` 启动必须在 `Application::_on_startup()` 之后；关闭经 `_on_shutdown()` 对称执行，析构只做幂等兜底。
- 场景画面获取只走 `ScenePresentationSubsystem`（离屏 output + view binding + `get_ui_surface`）；overlay/拾取/统计用其 editor 扩展接口，不得直连渲染器。
- 依赖方向：Panels → Core/Services/Widgets；Shell 组织 Panels；App 组装一切；Core 不反向依赖上层。
- `EditorEventBus` 与各 Service 均假定主线程访问。

## 验证

对齐 `docs/VERIFY.md` "Editor 面板 / UI"行。需要鼠标、键盘、拖放或窗口交互的项目只由人类执行；Agent 仅运行自动化命令、检查只读截图/日志并移交清单，不得直接驱动 UI 或自行声称人工项目通过：

- Agent：构建 + `run.bat editor Debug --smoke-test-seconds=120` readiness smoke + 相关自动化测试；只读检查截图与日志
- 人类：运行 `run.bat editor`，手工覆盖面板打开、交互与无报错日志
- Particle Inspector 人工清单：六个 header、Texture 搜索/拖放/recent、missing fallback、wrong-type 阻塞、soft disable retain、两种预览，以及保存/重载、reset/restore/remove/undo/redo
- 涉及场景生命周期（打开/保存/reload）时升级为 `run.bat all Debug --smoke-test-seconds=120`
- Terrain authoring 还需运行 focused create/import/export immutable-job、Target Size normalization/shared descriptor/layout matrix、路径逃逸、destination race、取消/临时件清理、catalog identity、stroke/layer/viewport/brush-overlay/save-generation/file-operation/reload-conflict-recovery/selective-history/`Ctrl+S` 行为测试、幂等历史门禁、稳定选择、锁定与 rollback/quarantine 契约，以及 Debug/Release 全量 `RunTests.bat`；brush overlay 或渲染布局改变 scene presentation output，必须额外运行双后端 `RunRenderGate.bat`。
- Terrain 人工签署必须由人类分别在 Vulkan/DX12 操作：Target Size `300`、`384`、`3500`、非法文本和独立 X/Z，确认 Enter/失焦规范化、derived labels、Create/Import 共用 target、矩形 Terrain 最终画面与 reload 失败保留旧画面/精确诊断；并覆盖 Hierarchy 直达、首次有效落笔自动层、7 个工具拖动期间的 80–100 ms 可见更新、Flatten 整笔固定平面、每次拖动单条 Undo/Redo、cancel/失焦无残留、关闭 Terrain 面板与改选非 Terrain 后立即退出笔刷并恢复 W/E/R、重新打开并重选同 Terrain 后恢复、编辑层排序/隐藏/锁定/强度、8 个材质槽，以及 v2 保存重载与 v1 加载后仅保存时升级。Agent 不得代签这些交互项。
